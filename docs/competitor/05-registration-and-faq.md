## Equipment

### What is provided?
An identical modular kit per team: ESP32 microcontroller, encoded motors, motor
driver, IMU, distance sensors, battery management system, buck converter and
battery pack.

## Experience

### Do I need experience?
None. That is the point.

### I have never soldered or used an ESP32. Is that a problem?
No. There is a 30 minute opening briefing covering the electronics, GitHub
basics and maze-solving strategies, and ElecSoc committee members and
postgraduate demonstrators are on the floor all day.

### How do I prepare?
A pre-recorded video series and written setup documentation are published in
advance. Do [A6 Laptop setup](06-laptop-setup.md) before the day so you are not
installing tools during the build.

### Can we practise?
Full size and mini practice mazes are open all day. One mini maze is built so
the fastest route cuts diagonals.

## AI tools

### Can we use an AI coding agent?
Yes, and we encourage it. Full policy in
[A4 AI coding agent policy](04-ai-agent-policy.md).

### Are there sponsor credits for it?
Anthropic is technical partner and provides a credits package. Details in
[A7 Sponsor credits](07-sponsor-credits.md).

### Will using an agent count against us?
No. You do need to be able to explain your own code. See A4.
