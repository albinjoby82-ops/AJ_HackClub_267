## Not yet confirmed

Do not invent these. Reference them as `[DECISION REQUIRED: ...]` or
`[INFO REQUIRED: ...]` in the affected page, and add them to
[HUMAN_DECISIONS_REQUIRED.md](audits/HUMAN_DECISIONS_REQUIRED.md).

- Detailed hour-by-hour running order

- Eligibility beyond "undergraduates and anyone else"
- Maze dimensions, cell size, wall height, wall thickness, post size
- Number of cells, goal area size, start cell position and orientation
- Maximum micromouse dimensions
- Number of runs permitted per team, total time on maze, timeout per run
- Timing method and who operates it
- Handling and touch penalties
- Scoring formula and tie breakers

- Filming and photography arrangements and opt-out
- Named code of conduct reporting contacts and a reporting channel
- On-the-day emergency contact number
- Whether teams may bring their own components or tools
- Whether pre-event code is permitted, and any starter repository URL
