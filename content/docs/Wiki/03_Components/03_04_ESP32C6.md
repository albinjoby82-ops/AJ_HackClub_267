# ESP32-C6

The ESP32-C6 is a `3.3 V` microcontroller platform with Wi-Fi, Bluetooth Low Energy, and IEEE 802.15.4 radio support. Hack Club projects may use an **ESP32-C6 development board**, which adds USB, voltage regulation, buttons, and accessible header pins around the ESP32-C6 module.

This page uses the **ESP32-C6-DevKitC-1** as the reference layout. Other ESP32-C6 boards can expose different pins and USB connections.

{: .warning-title}
> ESP32-C6 GPIO is 3.3 V
>
> Do not apply `5 V` to a GPIO pin. Check every connected sensor, module, and programmer for compatible logic levels. Use a suitable level shifter when required.

## Why use it?

- Wireless projects
- Bluetooth sensors and controls
- Matter, Thread, or Zigbee experiments where supported by the chosen software
- Faster or more memory-intensive embedded projects
- Low-power connected devices
- USB-capable projects on supported boards

## Before wiring

1. Identify the exact board model and revision.
2. Open its official pinout.
3. Check which GPIOs are exposed.
4. Identify `3V3`, `5V`, and `GND` pins carefully.
5. Check strapping pins and pins used by onboard hardware.
6. Confirm that the selected Arduino board package or ESP-IDF target matches the board.

On the ESP32-C6 chip, some pins affect boot configuration. The DevKitC-1 documentation identifies strapping pins including `GPIO8`, `GPIO9`, and `GPIO15` along with JTAG-related signals. Avoid attaching circuits that force boot-sensitive pins to the wrong state during reset.

## Install with Arduino IDE

1. Install Arduino IDE 2.
2. Add Espressif's Arduino-ESP32 board package using the official installation instructions.
3. Connect the board with a data-capable USB cable.
4. Select the matching ESP32-C6 board, such as **ESP32C6 Dev Module**, when appropriate.
5. Select the serial port.
6. Compile and upload a simple example.

The exact upload process depends on the development board. If automatic upload fails, hold the board's **BOOT** button, start the upload, and release it when the upload begins; use this only when appropriate for the board.

## Example: blink an LED

Use a GPIO that is safe and accessible on your exact board. Replace the example pin after checking its pinout.

```cpp
const int LED_PIN = 7; // Example only: verify your board

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(500);
  digitalWrite(LED_PIN, LOW);
  delay(500);
}
```

Do not assume `LED_BUILTIN` exists or uses the same pin on every ESP32-C6 board.

## Example: read a button

Connect a button between a suitable GPIO and `GND`.

```cpp
const int BUTTON_PIN = 2; // Verify this GPIO for your board

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  Serial.begin(115200);
}

void loop() {
  Serial.println(digitalRead(BUTTON_PIN) == LOW ? "pressed" : "released");
  delay(50);
}
```

## Example: scan for Wi-Fi networks

```cpp
#include <WiFi.h>

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  WiFi.disconnect();
  delay(100);

  int count = WiFi.scanNetworks();
  for (int i = 0; i < count; i++) {
    Serial.print(WiFi.SSID(i));
    Serial.print("  RSSI: ");
    Serial.println(WiFi.RSSI(i));
  }
}

void loop() {}
```

Do not publish real network passwords in source files. Use a separate secrets file excluded from Git when a project needs credentials.

## Serial output

ESP32 examples commonly use `115200` baud:

```cpp
void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("ESP32-C6 started");
}

void loop() {}
```

Set Serial Monitor to the same baud rate. Some boards expose more than one USB or serial connection, so choose the port associated with the uploaded program.

## Power and peripherals

- Use `3.3 V` logic on GPIO.
- Do not power motors, servos, relays, or LED strips from GPIO pins.
- Use drivers and separate suitable supplies for larger loads.
- Join grounds when two low-voltage systems exchange ordinary signals.
- Add local decoupling near external ICs and sensors.
- Check whether an analogue, PWM, I²C, SPI, or UART function is available on the chosen pins.

## Common problems

### The board does not appear

Check the USB cable, connector, port, operating-system permissions, and whether the board uses native USB or a USB-to-serial converter.

### Upload waits or fails

Confirm the board target and port. Disconnect circuits from boot-sensitive pins and try the documented BOOT/RESET sequence.

### The board continually resets

Check supply stability, peak current, USB cable quality, external loads, and serial reset messages.

### Wi-Fi code compiles for another ESP32 but not this board

Update the official Arduino-ESP32 package and confirm that the library and feature support ESP32-C6.
