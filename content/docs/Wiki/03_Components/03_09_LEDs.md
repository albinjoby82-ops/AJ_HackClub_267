# LEDs

A light-emitting diode (LED) produces light when current flows in its forward direction. Like other diodes, it has polarity.

## Identifying polarity

On many through-hole LEDs:

- Longer lead: anode (`+`)
- Shorter lead: cathode (`−`)
- Flat edge on package: cathode

These markings can be cut or inconsistent, so confirm uncertain parts with diode mode.

## Always limit current

Connect an ordinary LED with a series resistor:

```text
GPIO ── resistor ── LED ── GND
```

```text
R = (Vsupply - Vforward) / I
```

For a `5 V` output, `2 V` LED, and `10 mA`:

```text
R = (5 - 2) / 0.010 = 300 Ω
```

Use a standard value such as `330 Ω`.

{: .warning}
> Never connect a standard LED directly across a supply or GPIO pin. Current can rise enough to damage the LED or controller.

## RGB LEDs

An RGB LED contains red, green, and blue dies.

- **Common cathode:** shared negative connection; drive colour pins high through resistors.
- **Common anode:** shared positive connection; drive colour pins low through resistors.

Use one current-limiting resistor per colour. The pin order varies, so check the datasheet or test carefully.

## Addressable LEDs

Parts such as WS2812-family LEDs contain a controller and receive digital data. They still require suitable power, decoupling, common ground, correct logic levels, and careful current planning.

## Common problems

- LED installed backwards
- Missing or incorrect resistor
- RGB common-anode/common-cathode confusion
- Wrong RGB pin order
- GPIO cannot supply the requested current
- Addressable strip power voltage or data timing is incorrect
