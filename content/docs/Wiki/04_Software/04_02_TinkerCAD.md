# TinkerCAD
Tinkercad is a free, online tool by Autodesk that lets us model and test electronics circuits without us having to assemble them. It can also be used for 3D models and coding.

Because Tinkercad runs entirely in the browser, it is the fastest way to try a circuit before building it for real. This walkthrough shows how to place an Arduino, wire components, and run a simulation.
