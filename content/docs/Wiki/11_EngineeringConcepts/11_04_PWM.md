# PWM and Duty Cycle

Pulse-width modulation (PWM) switches an output between ON and OFF rapidly. The fraction of time spent ON is the **duty cycle**.

```text
duty cycle = on time / total period
```

- `0%`: always off
- `50%`: on for half of each period
- `100%`: always on

```cpp
analogWrite(9, 128);
```

On a classic Arduino Uno PWM pin, `128` is roughly 50% duty cycle. Despite the function name, this is normally a digital pulse train rather than a true steady analogue voltage.

## Why it works

- An LED appears dimmer because eyes average rapid flashes.
- Motor inductance and inertia smooth pulses into approximate control.
- A low-pass filter can produce a smoother voltage.

PWM that is too slow may flicker or make a motor audible. PWM that is too fast may increase switching losses.

## PWM is not servo control

Hobby servos use timed command pulses where pulse width represents target position. This differs from using duty cycle to control LED brightness.
