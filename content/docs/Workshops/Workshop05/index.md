# Workshop 05 - Reaction Timer

Build a small game that waits for a random time, flashes an LED and measures how quickly you press a button. It works with a basic Arduino kit or entirely in Tinkercad.

## What you need

- Arduino Uno-compatible board and USB cable
- Breadboard and jumper wires
- One push button
- One LED and a `220 Ω` to `330 Ω` resistor
- Optional piezo buzzer

## What you will learn

- Read a digital input reliably
- Use the Arduino's internal pull-up resistor
- Measure elapsed time with `millis()`
- Build a simple state-based program
