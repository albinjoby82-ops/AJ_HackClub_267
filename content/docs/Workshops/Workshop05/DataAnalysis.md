# Advanced Task 2 - Analyse Reaction-Time Data

Run at least 20 valid rounds and print one CSV row per round:

```text
round,reaction_ms,false_starts
1,284,0
2,251,0
```

Copy the data into a spreadsheet or analyse it in Python.

Calculate:

- Mean and median reaction time
- Fastest and slowest valid times
- Range and standard deviation
- Whether performance changes with practice

{: .challenge-title}
> Test a hypothesis
>
> Compare visual and audio cues, left and right hands, or early and late rounds. Keep everything else consistent and explain whether the data supports your prediction.
