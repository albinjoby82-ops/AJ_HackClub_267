# Introduction

An RGB LED contains red, green and blue light sources in one package. By changing each colour's brightness, one microcontroller can mix a wide range of colours.

In this workshop you will:

- Wire an Arduino and an RGB LED safely
- Use PWM to control brightness
- Mix colours in code
- Send and inspect messages over Serial
- Understand how addressable LED strips reduce the number of control wires

Start with a single RGB LED. It makes every connection visible and keeps mistakes inexpensive. Once that works, the same ideas prepare you for addressable LEDs such as the WS2812.

## Choose your route

- **No equipment:** use the free Tinkercad Circuits simulator.
- **Basic kit:** use an Arduino Uno-compatible board, a breadboard, jumpers, an RGB LED and three resistors.

The [at-home setup](AtHome.md) explains both routes.
