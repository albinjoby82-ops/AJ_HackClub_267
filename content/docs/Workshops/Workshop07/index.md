# Workshop 07 - Introduction to Codex

Use Codex as a project collaborator: give it the right files, ask for a focused change, review the result and share the work safely through GitHub. The advanced tasks bring in project context from tools such as Google Drive and email.

## What you need

- Access to Codex
- A local practice repository that you are allowed to change
- A GitHub account and either GitHub Desktop or Git
- A text editor such as Visual Studio Code
- Optional access to Google Drive, Gmail or Outlook for the connected-tools task

Do not practise in an important production repository. A small fork or disposable repository is ideal.

## What you will learn

- Give Codex access to the correct project folder
- Write a clear task with a goal, context, constraints and checks
- Review and verify changes before accepting them
- Use branches, commits, pushes and pull requests with Codex
- Connect approved external tools without exposing credentials
