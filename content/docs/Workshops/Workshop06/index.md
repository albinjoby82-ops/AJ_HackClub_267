# Workshop 06 - ESP32-C6 Wi-Fi Explorer

Turn an ESP32-C6 into a tiny wireless survey tool. You only need the board and a data-capable USB cable; the workshop scans nearby network names and signal strengths without connecting to them.

## What you need

- An ESP32-C6 development board
- A data-capable USB cable
- Arduino IDE with ESP32 board support installed

## What you will learn

- Select and upload to an ESP32-C6
- Scan for nearby Wi-Fi networks
- Compare RSSI signal-strength values
- Present results clearly in the Serial Monitor
