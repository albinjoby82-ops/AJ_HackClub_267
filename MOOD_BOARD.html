Design Guidelines

Light Mode First, Dark Mode Ready

Primary design is in light mode with deep teal backgrounds and mint accents. Dark mode uses slightly darker backgrounds (#0D2F39 for background, #1A4A5A for surfaces) with increased contrast for text and subtle borders.

Spacing & Grid

Use the spacing scale (8px, 16px, 24px, 40px, 64px) consistently. Container max-width 1200px. Mobile: full width with 16px padding.

Imagery & Overlays

All images use a dark teal gradient overlay (40-60% opacity). This ensures text legibility and maintains design consistency across photos.

Interactivity

Hover states: cards lift slightly (transform: translateY(-4px)), shadows deepen. Buttons scale to 1.02. All transitions: 0.3s ease.
